# Spline Computation Library

A C++ library for B-spline computations with Python bindings.

## Building

### Prerequisites

- CMake
- C++ compiler (GCC, Clang, MSVC)
- Python 3.8+

### Python Package Installation

Install the package directly using pip, which will automatically handle the CMake build:

```bash
git clone --recursive https://github.com/mariocaballeroyus/splines.git
cd splines
pip install -e .
```

## Usage

After installation, you can import the Python module:

```python
import pysplines
```
